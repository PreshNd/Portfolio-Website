How categories work
  • Categories appear as filter tabs on the packages landing page.
  • Assign categories to packages in the Categories & Visa tab when editing a package.
  • Default categories cannot be deleted — only renamed.
  • Deleting a custom category removes it from any packages it was assigned to.
  • The slug must match exactly what the frontend tab uses.
